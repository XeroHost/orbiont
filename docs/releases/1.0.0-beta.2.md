# Orbiont 1.0.0-beta.2

This beta brings together the latest improvements to recovery, editing,
Bedrock management, performance and translations.

## Features and improvements

- A recovery and storage center for Java and Bedrock backups, with restoration
  and selection of older backups by age and retention count. Deletion requires
  explicit confirmation.
- A file editor with external change detection, backups before saving and draft
  protection when navigating away or closing the launcher.
- Coordinated Bedrock operations, recovery after interruptions, launch
  diagnostics and report export without account details or file paths.
- Normal Bedrock shutdown, with an additional confirmation to force-close the
  same process if it does not respond.
- Visible circular selection controls, readable storage sizes and a single
  scroll area in the storage dialog. Launch diagnostics refresh silently.
- On-demand text editor loading, account updates driven by events and smoother
  list scrolling.
- New interface text completed across all 33 supported languages.
- Updated dependencies and a compatible fix for the GLib iterator used on Linux,
  with its original licenses preserved.

## Security and reliability fixes

- A temporary key store failure preserves accounts and avoids replacing the
  existing encryption key.
- ZIP imports validate paths, limit entry counts and file sizes, check available
  disk space and use bounded reads.
- Recoveries use stable ordering, and inventories report incomplete results.
- Public frontend configuration is limited to the required variables.
- Java ownership checks, official Bedrock integration and signed automatic
  updates remain in place.

## Download

Get the installers for Windows, macOS and Linux directly from
[xerohost.net/orbiont](https://www.xerohost.net/orbiont#downloads).

Bedrock requires Windows and an officially licensed installation.
