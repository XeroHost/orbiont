# Orbiont 1.0.0-beta.2

Esta beta reúne las mejoras de ambas sesiones de desarrollo.

## Novedades y mejoras

- Centro de recuperación y almacenamiento para revisar copias de Java y Bedrock,
  restaurarlas y seleccionar copias antiguas por antigüedad y cantidad conservada.
  La eliminación requiere una confirmación explícita.
- Editor de archivos con detección de cambios externos, copias previas y
  protección de borradores al cambiar de página o cerrar el launcher.
- Gestión Bedrock con operaciones coordinadas, recuperación ante interrupciones,
  diagnóstico de inicio y exportación de un informe sin datos de cuenta ni rutas.
- Cierre normal de Bedrock; si no responde, confirmación adicional para forzar
  el cierre del mismo proceso.
- Selección circular visible en almacenamiento, tamaños legibles y un único
  desplazamiento en el modal. Diagnóstico con refresco automático silencioso.
- Editor de texto cargado bajo demanda, actualización de cuentas por eventos y
  mejoras del desplazamiento de listas.
- Nuevos textos completados en los 33 idiomas disponibles.
- Dependencias actualizadas y corrección compatible del iterador de GLib usado
  en Linux, conservando sus licencias.

## Correcciones de seguridad y fiabilidad

- Una indisponibilidad del almacén de claves conserva las cuentas y evita
  sustituir la clave de cifrado existente.
- Importaciones ZIP con validación de rutas, límites de tamaño y entradas,
  comprobación de espacio disponible y lectura acotada.
- Recuperaciones ordenadas de forma estable e inventarios que avisan cuando
  la información es parcial.
- Configuración pública del frontend limitada a las variables necesarias.
- Se mantienen la comprobación de compra Java, la integración oficial de
  Bedrock y las firmas del actualizador.

## Descargar

Instaladores directos para Windows, macOS y Linux:
[xerohost.net/orbiont](https://www.xerohost.net/orbiont#downloads).

Bedrock requiere Windows y una instalación oficial con su licencia.
Orbiont continúa en beta; agradecemos los reportes de errores y comentarios.
