# Orbiont 1.0.1

Orbiont leaves beta. This first stable release brings a more complete update
flow, a local diagnostics export and a broad set of reliability fixes for
installations, updates and the instance database.

## Update your content with more control

- **Update all** now opens a review window. Choose which projects to update,
  pick a specific compatible version for each one and read its changelog before
  applying anything.
- Selected updates run through the download manager, with progress,
  cancellation, retry and an automatic rollback if something fails. They keep
  running when you navigate to another page.
- Dependency conflicts are checked before any file changes, and the window
  explains which project blocks the update.
- When only one project has an update, Orbiont uses the regular single update.

## Diagnostics for support

- Save a diagnostic archive from **Settings → Resource management**. It contains
  app and system versions and up to eight launcher logs in a local ZIP file.
- Tokens, passwords, custom environment values and personal folder names are
  redacted. The archive never includes your database, account records or game
  files, and nothing is uploaded.
- Interface errors are now recorded in the launcher logs, with the same
  redaction and size limits.

## Reliability fixes

- Moving the launcher data folder now copies several files at once and reads
  each file fewer times, and the startup screen shows its real progress instead
  of appearing stuck near the end. Keep the
  launcher open until it finishes; your original folder is only removed after
  everything is copied and verified.
- Updates now verify that the downloaded version belongs to the same project.
- Fewer "database is locked" errors when several operations write at once.
- Interrupted or orphaned installations are detected and recovered, and failed
  rollbacks stay visible until they are resolved.
- Older install states and backups load correctly after upgrading.
- Updating content with duplicate files, disabled projects or incomplete
  metadata no longer fails or removes files you added yourself.
- Scanning an instance no longer rewrites unchanged files or their dates, and
  instance pages open faster.
- New instances finish installing before Orbiont adds the selected mod,
  resource pack, data pack or shader.
- Instances launch with their installed loader even when it disappears from the
  online catalog.
- Any valid custom Java installation is accepted, with a clear warning when it
  does not match the Java version the instance requires.
- Fixed Forge release dates with certain time zone offsets.
- Windows: the window no longer grows when it is restored, and AltGr works when
  assigning controls.
- Renaming content files outside Orbiont no longer breaks modpack updates.
- Importing or duplicating no longer copies a file over itself.
- Fixed the Files tab for instances stored under a resolved folder path on Windows.
- Featured modpacks load reliably again, and search filters keep their values.
- Log compaction notices and folder-in-use errors now show the correct product name.

## More skins

- Added 34 default skins, including the Dungeons Hero, Dungeons II Hero and
  Wilderness Bound collections.

## Languages

- The new interface text is available in all 33 supported languages.

## Download

Download the installers for Windows, macOS and Linux from
[xerohost.net/orbiont](https://www.xerohost.net/orbiont#downloads).
Installed copies of Orbiont update automatically.

Bedrock integration requires Windows and an officially licensed installation.
Feedback and bug reports are welcome.
